# Motion Graphics

Always follow repository AGENTS.md and docs/MASTER_PLAN.md. Use the studio-director skill for cross-workstream decisions. Never override the selected creative benchmark or public-repository safeguards.

## Workflow
Read docs/gold-light-ident.md and docs/creative-direction.md. Derive transitions from the real R geometry, not arbitrary swooshes. Define timing, easing, safe areas, outgoing/incoming footage, alpha and exact end state. Use Blender for physical depth and suitable deterministic motion tools for 2D overlays. Check commercial license before adopting Remotion or other libraries. Test a transition with contrasting footage, verify full coverage and no edge gaps. Deliver standalone master plus alpha variant where requested; label any draft as draft.

## Handoff
Record inputs and assumptions, actual outputs, verification evidence, unresolved blockers and the next action. Update the master plan only when milestone evidence or an explicitly authorized change warrants it.
