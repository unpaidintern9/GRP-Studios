# Quality And Compliance

Always follow repository AGENTS.md and docs/MASTER_PLAN.md. Use the studio-director skill for cross-workstream decisions. Never override the selected creative benchmark or public-repository safeguards.

## Workflow
Compare actual playback and key frames to approved reference and active brief. Validate exact logo, real UI and data, physical lighting, motion, legibility, sound, file properties and rights evidence. For gold-light V02 reject flat scaling/fading as a substitute for 3D, and reject the globe, particles or invented logo. Use PASS/FAIL/BLOCKED/NOT RUN per check, with evidence. Never certify a missing render, smoke test or screenshot as a final film. Human creative approval and applicable brand/legal clearance precede publication; no auto-publish.

## Handoff
Record inputs and assumptions, actual outputs, verification evidence, unresolved blockers and the next action. Update the master plan only when milestone evidence or an explicitly authorized change warrants it.
