# Brand Asset Integrity

Always follow repository AGENTS.md and docs/MASTER_PLAN.md. Use the studio-director skill for cross-workstream decisions. Never override the selected creative benchmark or public-repository safeguards.

## Workflow
Read docs/gold-light-ident.md and docs/studio-architecture.md. Use the original approved GRP mark and full lockup, never generated lettering or a replacement logo. Verify source identity, hash, dimensions, color and alpha. Request private copies of the PNG sources or validated vectors; the Terminal is read-only provenance only, not a dependency. If tracing a PNG, compare contours and overlays against the reference and document deviations. Preserve correct aspect ratio and proportions. Store brand files and sensitive evidence in ignored private paths, never public Git. Produce a private manifest with provenance, hashes and rights.

## Handoff
Record inputs and assumptions, actual outputs, verification evidence, unresolved blockers and the next action. Update the master plan only when milestone evidence or an explicitly authorized change warrants it.
