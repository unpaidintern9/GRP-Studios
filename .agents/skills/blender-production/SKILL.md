# Blender Production

Always follow repository AGENTS.md and docs/MASTER_PLAN.md. Use the studio-director skill for cross-workstream decisions. Never override the selected creative benchmark or public-repository safeguards.

## Workflow
Read docs/blender-team-setup.md and docs/gold-light-ident.md. Verify Blender executable and pinned version; use a generic smoke test before brand work. Use official curves or validated contour tracing, physical PBR metals, bevels, studio area lights, physically believable depth and camera motion. For the ident, animate lighting and camera rather than deforming glyph topology; render representative stills before the full 120-frame sequence at 24 fps. Use Cycles for final realism, bounded draft samples and resolution first. Save editable scene, reproducible source scripts, settings and frame sequence privately. If Blender is unavailable, report the blocker and provide executable source if useful; never substitute a flat reveal and claim 3D completion.

## Handoff
Record inputs and assumptions, actual outputs, verification evidence, unresolved blockers and the next action. Update the master plan only when milestone evidence or an explicitly authorized change warrants it.
