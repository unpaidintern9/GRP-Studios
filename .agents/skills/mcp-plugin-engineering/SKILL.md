# Mcp Plugin Engineering

Always follow repository AGENTS.md and docs/MASTER_PLAN.md. Use the studio-director skill for cross-workstream decisions. Never override the selected creative benchmark or public-repository safeguards.

## Workflow
Read docs/MASTER_PLAN.md and docs/blender-team-setup.md. Build MCP-first without a website requirement. Use a versioned plugin interface, typed schemas, explicit tool capabilities, private storage and local stdio first. Implement allowlisted templates, validated paths, bounded jobs, cancellation, timeouts, logs and status. No arbitrary remote Python/shell, shared Terminal credentials or unattended paid calls. Test with fake adapters and actual runtime smoke tests independently; remote team access requires authentication, authorization and isolated worker execution. Only advertise tools actually implemented; add modules incrementally without rebuilding unrelated engines.

## Handoff
Record inputs and assumptions, actual outputs, verification evidence, unresolved blockers and the next action. Update the master plan only when milestone evidence or an explicitly authorized change warrants it.
